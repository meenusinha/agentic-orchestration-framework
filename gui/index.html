Setup

    1. Install

    Installs the hash-verified Python packages into the framework's own virtual environment. Nothing is installed into your system Python.

    2. Embedding model

    The approved model ibm-granite/granite-embedding-small-english-r2 (Apache 2.0, ~95 MB) is included in the framework's models/ folder. Every file is checked against its pinned SHA-256 fingerprint. You can also type the path of another folder holding the approved model to use it in place — nothing is ever downloaded.

    3. Repositories

    Which repositories should be connected? Add at least two — for example the repo that holds the IDL interfaces, the server and the clients. Add each one either from a folder you have already cloned, or from its Git URL and branch.

    Already cloned

    Type or paste the repository's folder path, or choose it.

    4. Review

    What the scan found in each repository. Choose which folders to index (untick a folder to exclude it), correct any folder role, and tell us what unknown file types contain — nothing is guessed silently.

    Scanning…

    5. Configure

    Writes each repository's settings, connects the repos to each other and generates the VS Code + GitHub Copilot configuration (MCP servers, Copilot instructions and the agent skill).

    6. Create GraphRAG

    Create the GraphRAG for these repositories now? It parses every repository into whole functions, classes and IDL operations, links them across repositories and builds the search index — locally, no AI service involved. First, an estimate of how long it takes on this computer: for large repositories you can create it in batches, a few components at a time.
