Agentic Orchestration

    1. Install

    Installs the hash-verified Python packages into the framework's own virtual environment. Nothing is installed into your system Python.

    2. Embedding model

    Point to your copy of the approved model ibm-granite/granite-embedding-small-english-r2 (Apache 2.0, ~95 MB). It is copied into the framework and checked against its pinned SHA-256 — nothing is downloaded.

    3. Repositories

    Choose at least two repositories that should know about each other — for example the repo that holds the IDL interfaces, the server and the clients.

    4. Review

    What the scan found in each repository. Correct any folder role, and tell us what unknown file types contain — nothing is guessed silently.

    Scanning…

    5. Configure

    Writes each repository's settings, connects the repos to each other and generates the MCP configuration for Claude Code, Cursor and VS Code.

    6. Create GraphRAG

    Create the GraphRAG for these repositories now? It parses every repository into whole functions, classes and IDL operations, links them across repositories and builds the search index — locally, no AI service involved. The first build takes a while.

    Queries

    Use the query field at the top. Every result is also saved as a new Markdown file in — earlier results are never overwritten.
