Agentic Orchestration

Setup

    1. Install

    Installs the hash-verified Python packages into the framework's own virtual environment. Nothing is installed into your system Python.

    2. Embedding model

    The approved model ibm-granite/granite-embedding-small-english-r2 (Apache 2.0, ~95 MB) is included in the framework's models/ folder. Every file is checked against its pinned SHA-256 fingerprint. Only if it is missing do you need to point to another copy — nothing is ever downloaded.

    3. Repositories

    Which repositories should be connected? Add at least two — for example the repo that holds the IDL interfaces, the server and the clients. Add each one either from a folder you have already cloned, or from its Git URL and branch.

    4. Review

    What the scan found in each repository. Correct any folder role, and tell us what unknown file types contain — nothing is guessed silently.

    5. Configure

    Writes each repository's settings, connects the repos to each other and generates the VS Code + GitHub Copilot configuration (MCP servers, Copilot instructions and the agent skill).

    6. Create GraphRAG

    Create the GraphRAG for these repositories now? It parses every repository into whole functions, classes and IDL operations, links them across repositories and builds the search index — locally, no AI service involved. The first build takes a while.
